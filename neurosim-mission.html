What is this simulation?

The dynamics, fictional vehicle and planet presets, integration step (0.1 s), boundary conditions and landing success thresholds are ported from NeuroSim's source environment. Its published repository has a known Python syntax issue in the info dictionary, and there is no trained checkpoint committed for public AI inference. This is an independent browser-native implementation of the intended manual environment, not the original Pygame renderer or a trained autonomous landing controller.
